# Bomb Pot 抽選アプリ

ポーカー卓で45分ごとにボムポットを抽選するための一枚もんのWebアプリ。

## 使い方

### Macで開く（ローカル動作確認）
```bash
open ~/Documents/poker-bombpot/index.html
```

### スマホで使う（推奨）
**方法A: ローカルWi-Fi経由**
1. Mac でサーバ起動:
   ```bash
   cd ~/Documents/poker-bombpot && python3 -m http.server 8000
   ```
2. Mac のIP確認: `ipconfig getifaddr en0`
3. スマホのSafariで `http://<MacのIP>:8000` を開く
4. 「ホーム画面に追加」でアプリっぽく使える

**方法B: AirDropで送る**
- `index.html` をスマホにAirDropして、ファイルアプリから開く

**方法C: 公開ホスティング（卓に来る前に毎回ロード不要にしたいなら）**
- GitHub Pages / Vercel / Netlify に1ファイル置けば終わり。必要になったら言って。

## 機能

- 45分カウントダウンタイマー（間隔は設定で変更可）
- 0秒到達で自動抽選：ゲーム名 + BB数（1〜6）を全画面表示
- 音 + バイブ通知
- 「今すぐ抽選」で手動でも回せる
- ゲームプールON/OFF、BB範囲、間隔は設定でいじれる
- 履歴20件保存
- 画面ロック防止（Wake Lock API、対応ブラウザのみ）

## ゲームプール初期値

NLHダブルボード / PLO / PLOダブルボード / ビッグオー(PLO5) / ビッグオーダブルボード / クルシュベル / 2-7 / バドゥーギ

## 注意

- iOS Safari の場合、音を鳴らすには最初にアプリ内で1回でも操作（スタート押下等）が必要（ブラウザのオートプレイ制限）
- Wake Lockは画面表示中だけ。ブラウザがバックグラウンドに行くと止まる場合あり → 卓では画面表示しっぱなしで
